vero-notes demo

Each section below has a Discuss button. Chat about a section, and when you're ready, tell the agent to update my doc. The section is rewritten in place and the page reloads itself.

1. Overview

This page is a living document served from your local disk. A Claude Code agent sits on the other side of the web server and can discuss any section with you, then rewrite that section in place when asked. The file itself is plain HTML in a revision-controlled directory, so every update the agent makes is an ordinary diff.

2. How the chat works

Clicking Discuss reveals a text area scoped to this section only. Whatever you type is sent to the agent along with the section id. The first time you press Send, the entire text area is transmitted, so a freshly attached agent gets the full history. Replies from the agent are appended into the same text area without a page reload.

3. How updates work

When you tell the agent to update the document, it rewrites only the content of the section under discussion, splicing new HTML between hidden marker comments. Your chat history for every section is embedded into the regenerated file's hidden text areas, so after the automatic reload, clicking the chat button shows the conversation right where you left it.

4. Architecture

A single Python process does double duty: it speaks MCP over stdio to the Claude Code agent that spawned it, and it runs a small HTTP server on localhost that serves this page and relays chat both ways. The page's static JavaScript polls for agent replies and for a new file version; when the version changes, it reloads.

5. Try it

Open the chat on this section and ask the agent to rewrite it — a haiku about margins, a denser technical summary, whatever you like. Say update my doc and watch the page regenerate itself. Every change lands in this file on disk, so git diff shows exactly what the agent did.
